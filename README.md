# Suite Settings

The settings of Love Suite's apps in one window: Explorer (Finder, files, windows, sidebar,
toolbar, Trash), Desktop, Bar, Viewer, Clipboard, and settings profiles kept on this Mac or in iCloud
Drive. Its background agent, Suite Settings Agent, covers in System Settings the settings a running suite
app takes over, with a button opening that app's settings. Still to come: finding and installing the
suite's other apps.

Install: `brew install --cask love-suite/tap/settings` (once the first release is out).

Development: `swift build`, `scripts/make-app.sh` (Swift 6.4.2, macOS 13 or later).
